# Wordle (React)

A small five-letter Wordle-style guessing game built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Day 1 milestone (November 17, 2026)

- Add Vite-compatible React entry point
- Display guesses as colored letter tiles
- Allow up to six guesses at the word `REACT`

> This is a learning project. Input handling and scoring will be improved in later commits.
